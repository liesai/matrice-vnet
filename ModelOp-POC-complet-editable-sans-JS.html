Les flèches restent à leur position initiale. Les modifications sont temporaires dans cet onglet ; l’impression conserve le rendu visible, pas une source éditable.

Affichage

Réglages relatifs à la position d’origine. « +60 » déplace vers la droite ou vers le bas ; « −60 » vers la gauche ou vers le haut. Remettre les deux axes sur 0 pour rétablir la position. Le glisser-déposer libre nécessite du JavaScript.
